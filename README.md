## About this repository

A static single-page site: `index.html`, `style.css`, and `script.js`, with no framework and no
build step. GitHub Pages serves it from the `main` branch. To preview it locally, open
`index.html` in a browser, or run `python -m http.server 8000` in this folder and go to
http://localhost:8000.
